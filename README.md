## Featured projects

### CareTrack — care-facility billing SaaS
Full billing engine for care facilities: monthly and medical charges, post-expiry daily fees, per-client negotiated rates, a running payment ledger with credit/overpayments, PDF receipts, and 6 alert types auto-generated daily via cron with deduplication.
- Stack: React, Node/Express, MongoDB, daisyUI, JWT
- Live: [theserenityplace.vercel.app](https://theserenityplace.vercel.app) · Repo: [carefacility](https://github.com/bkoimett/carefacility)
- What it shows: full-stack ownership, complex business logic, production B2B SaaS

### Detecto — real-time person detection web app
Upload an image and get YOLOv8 bounding-box detections with confidence scores, inference-time stats, and upload history analytics. Clean REST API (FastAPI), React frontend, fully documented.
- Stack: React + Vite, FastAPI, YOLOv8, Render
- Live: [frontend-rho-self-41.vercel.app](https://frontend-rho-self-41.vercel.app) · Repo: [detecto](https://github.com/bkoimett/detecto)
- What it shows: ML/AI integration, API design, repo hygiene

### task-mixer — offline-first micro-task PWA (48-hour hackathon)
Offline task discovery and application with optimistic updates, an IndexedDB sync queue with retry, verifiable offline skill badges, and conflict detection powered by a Go WASM module. My most-starred repo.
- Stack: React + Vite + Tailwind, Service Worker, IndexedDB (Dexie), Go WASM
- Repo: [task-mixer](https://github.com/bkoimett/task-mixer)
- What it shows: resilient architecture, service workers + IndexedDB, delivery speed

### land-ledge — blockchain land title verification
Title-deed verification platform on Solana: live Ethereum event subscriptions (LandRegistered, OwnershipTransferred), registration and ownership-transfer dashboards, and a history search page.
- Stack: Solidity (Hardhat), Go backend (gin + go-ethereum), Next.js/TypeScript
- Live: [land-ledge frontend](https://land-ledge-git-frontend-benjie-bkoimetts-projects.vercel.app) · Repo: [land-ledge](https://github.com/bkoimett/land-ledge)
- What it shows: web3, smart contracts, Go blockchain services

### opencode-ntfy-approve — interactive mobile approval plugin (open source)
OpenCode plugin that sends tool-permission requests to your phone via ntfy with Allow/Reject buttons — approve tools straight from your lock screen, no desktop needed. The only OpenCode+ntfy plugin with interactive approval.
- Stack: TypeScript, OpenCode plugin SDK, ntfy
- Repo: [opencode-ntfy-approve](https://github.com/bkoimett/opencode-ntfy-approve)
- What it shows: developer tooling, TypeScript, shipping a real open-source utility

### Personal portfolio + CMS
My own portfolio and blog, built as a production-grade CMS: Markdown case-study rendering, JWT auth with bcrypt and login rate-limiting, dark-mode glassmorphic design. Built with React 19 and Tailwind v4.
- Stack: React 19, Tailwind v4, Node/Express, MongoDB
- Live: [bkoimett-portofolio.vercel.app](https://bkoimett-portofolio.vercel.app) · Repo: [bkoimett-portofolio](https://github.com/bkoimett/bkoimett-portofolio)
